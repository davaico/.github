# Davai

**Technology services.** Tailored software and AI agents for businesses, built and kept in production by our team in Paris.

## We build for value. When the stars align, we open source.

Software meant to run for ten years cannot depend on one vendor's pricing or mood. Every system we ship stands on work that others chose to share: Linux, Go, FFmpeg, Odoo and thousands of smaller projects. We are a service company, not a foundation, so we give back what our model allows: when something we build is useful beyond one client, we publish it here.

## Releases

- **[Square PoS Odoo](https://github.com/davaico/odoo-square)**: a production Odoo 17 addon that connects Square POS to Odoo Sales, Accounting and Inventory, with webhooks, orders, refunds, exchanges and stock sync. AGPL-3.0.
- **[Square Combo](https://github.com/davaico/square-combo)**: syncs each day's Square revenue into Combo, the HR and scheduling platform, location by location, for several businesses at once.
- **[Attio CLI](https://github.com/ekrtf/attio-cli)**: a command line for you or your agent to manage the Attio CRM from the terminal.
- **Odoo PoS Revolut**, in progress: an open source integration between Odoo and Revolut POS, developed with Revolut.

## What we do

Infrastructure, agent harnesses, apps, Odoo, Salesforce, Square, local AI, and AI-built prototypes taken to production. Every project follows the same model: tailored software built with applied AI, then kept secure, supervised and evolving.
